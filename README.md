# Python Skin Guide

A single-page reference guide to python species, their IUCN Red List status, CITES Appendix listings, and a self-check tool for spotting python-leather items sold without proof of legal origin.

**Live site:** https://heyu-hub.github.io/python-skin-guide/

Built for BL5314 (CITES and Illegal Wildlife Trade), NUS.

## About

Static HTML/CSS/JS, no backend — all images are embedded directly in the page. Hosted free on GitHub Pages.

## Running locally

Open `index.html` in any browser, or serve the folder:

```
python3 -m http.server
```
